# Introducción

El presente repositorio corresponde al portafolio digital desarrollado durante el curso Técnicas de análisis y modelación en Ciencias Ambientales.El objetivo general del curso fue distinguir y aplicar diferentes técnicas de análisis y modelación para el tratamiento de datos multivariados y no lineales utilizados en el estudio de problemáticas ambientales.
A lo largo del semestre se trabajó con herramientas de programación y análisis estadístico en R, enfocadas en la interpretación de datos ambientales y la construcción de modelos matemáticos y estadísticos. Entre los principales temas abordados se encuentran la introducción a la modelación ambiental, modelos estadísticos, regresión lineal, regresión de Poisson, regresión logística, regresión multinomial, ecuaciones diferenciales, modelos de redes y análisis de series de tiempo.
Este portafolio reúne los ejercicios, scripts, bases de datos y actividades prácticas desarrolladas durante el curso, organizadas de manera estructurada con el propósito de evidenciar el aprendizaje y la aplicación de distintas técnicas de análisis y modelación en ciencias ambientales.

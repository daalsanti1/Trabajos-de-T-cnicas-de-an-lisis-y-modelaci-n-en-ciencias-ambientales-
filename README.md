# Trabajos-de-T-cnicas-de-an-lisis-y-modelaci-n-en-ciencias-ambientales-
Portafolio digital de Técnicas de análisis y modelación en ciencias ambientales, que incluye modelos estadísticos y herramientas de análisis desarrolladas en R, como regresión lineal, Poisson, logística, multinomial, ecuaciones diferenciales, modelos de redes y series de tiempo.

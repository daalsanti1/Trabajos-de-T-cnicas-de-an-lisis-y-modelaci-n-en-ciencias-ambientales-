# Introducción

El presente repositorio corresponde al portafolio digital desarrollado durante el curso Técnicas de análisis y modelación en Ciencias Ambientales.El objetivo general del curso fue distinguir y aplicar diferentes técnicas de análisis y modelación para el tratamiento de datos multivariados y no lineales utilizados en el estudio de problemáticas ambientales.
A lo largo del semestre se trabajó con herramientas de programación y análisis estadístico en R, enfocadas en la interpretación de datos ambientales y la construcción de modelos matemáticos y estadísticos. Entre los principales temas abordados se encuentran la introducción a la modelación ambiental, modelos estadísticos, regresión lineal, regresión de Poisson, regresión logística, regresión multinomial, ecuaciones diferenciales, modelos de redes y análisis de series de tiempo.
Este portafolio reúne los ejercicios, scripts, bases de datos y actividades prácticas desarrolladas durante el curso, organizadas de manera estructurada con el propósito de evidenciar el aprendizaje y la aplicación de distintas técnicas de análisis y modelación en ciencias ambientales.

##Explicación del repositorio

Su propósito es reunir y organizar los trabajos prácticos realizados durante el semestre mediante el uso de programación en R y herramientas de modelación estadística y matemática aplicadas a problemas ambientales.

El repositorio incluye scripts ejecutables, bases de datos en formato .csv, gráficas y explicaciones breves para cada uno de los temas vistos en clase. Los contenidos abarcan diferentes técnicas de análisis y modelación utilizadas en ciencias ambientales, permitiendo aplicar herramientas estadísticas, modelos matemáticos y métodos computacionales para el análisis e interpretación de datos.

## Temas incluidos en el portafolio

### Modelo de regresión lineal
Se aplicó un modelo de regresión lineal para analizar la relación entre variables ambientales y evaluar tendencias dentro de los datos obtenidos.

### Regresión de Poisson
Se utilizó la regresión de Poisson para modelar datos de conteo y analizar eventos o frecuencias relacionadas con variables ambientales.

### Regresión logística
Se desarrolló un modelo de regresión logística para estudiar variables de respuesta binaria y su relación con distintos factores ambientales.

### Regresión multinomial
Se aplicó una regresión multinomial para analizar variables categóricas con múltiples posibles resultados.

### Ecuaciones diferenciales
Se implementaron ecuaciones diferenciales para representar dinámicas y cambios en sistemas ambientales a través del tiempo.

### Modelos de redes
Se trabajó con modelos de redes para representar interacciones y relaciones entre diferentes elementos dentro de sistemas ambientales.

### Series de tiempo
Se realizó análisis de series de tiempo para estudiar el comportamiento temporal de variables ambientales y detectar patrones o tendencias.
